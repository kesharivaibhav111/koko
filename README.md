# Koko - 3D Birthday Celebration Website ✨

An interactive 3D birthday celebration website created for bestie **Koko**.

## Features
- **3D Hero Stage**: Floating 3D starry constellation & particle effects.
- **Interactive 3D Cake**: Layered cake with realistic candle flames you can tap or blow out to trigger a dual-cannon confetti explosion.
- **3D Memory Cylinder**: 360-degree cylindrical drag/touch carousel displaying all 14 bestie photos in polaroid style.
- **Spotlight Video Theater**: Glassmorphic cinema card with ambient reactive glow and live reaction buttons.
- **Bento Accolades Grid**: 3D parallax tilt cards celebrating why Koko is the GOAT.
- **3D Mystery Gift Unboxing**: Isometric 3D gift box with unboxing animation and certified friendship plaque.
- **Scrapbook Wall**: High-resolution photo mosaic grid with full-screen lightbox modal.
- **Web Audio Synthesizer**: Procedural Happy Birthday chime melody and custom sound effects with zero external audio dependencies.

## Live Preview
Open `index.html` in any modern web browser or serve with:
```bash
python3 -m http.server 8080
```
